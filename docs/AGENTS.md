# Documentation instructions

## For Humans

As Anyo develops, conversations need to become discoverable decisions and actionable plans. These instructions connect every document to the same writing workflow so readers can understand both the context and the current state of the work.

## Scope

These instructions apply to `docs/` and its subdirectories.

- Follow [the anyo-docs skill](../skills/anyo-docs/SKILL.md) when creating, updating, or organizing documents.
- Read [the documentation index](README.md) and relevant existing documents first.
- Keep shared knowledge separate from component-specific details when those components exist, and maintain links from the index.
